# Renta Robo

Airbnb-light marketplace to rent real humanoid robots by skill. Average Joes. Skills, not specs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43180](http://127.0.0.1:43180).

Public signed-out site: [https://humaragent-source.github.io/rent-a-bot/](https://humaragent-source.github.io/rent-a-bot/). Static export in `docs/` on `main`. No Vercel.

## What’s on the phone

- Brand **Renta Robo**, lockup `Renta Robo -` plus a muted last-word slot (Bot → Nurse → Helper → Walker → Cleaner → Gardener → Trainer → Cook → Bot)
- Five real machines at **$18/hr** on the card. No ratings. Photos are 4:5 listing crops in `public/img/`.
  - Optimus — Errands, Clean — 0.8 mi — `optimus.jpg`
  - G1 — Kids, Gym — 1.2 mi — `g1.jpg`
  - NEO — Clean, Kids, Errands — 1.1 mi — `neo.jpg`
  - Atlas — Gym — 2.0 mi — `atlas.jpg`
  - Figure 02 — Errands — 1.6 mi — `figure02.jpg`
- Waitlist: **I want to rent** / **I have a robot** (localStorage on GitHub Pages)

## Out of scope

- Checkout or a public cart
- Costume / generated robot portraits
- Coastal Grade, Andres Log, and Ascendr
